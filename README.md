# MiniMax H3 Ref2V MV Workflow

ComfyUI workflow for generating multi-clip music videos with
MiniMax H3 Reference-to-Video.

## Features

- MiniMax H3 Reference-to-Video
- Multi-clip MV generation
- Individual duration settings for each clip
- Master audio support
- Motion continuity between clips
- Video upscaling
- Designed for lower VRAM environments

## Workflow

Download:

`MiniMax_H3_Ref2V_MV.json`

Drag the JSON file into ComfyUI.

## Required Models

- MiniMax H3 Ref2V model
- MiniMax H3 Video VAE
- MiniMax H3 Audio VAE
- Qwen3-VL MiniMax H3 text encoder

## Notes

Model files are not included in this repository.

Reference images and audio files must be prepared by the user.
